# Aartaler Asset Directory

This directory contains reference copies of branding assets for the
Aartaler (ARTLR) token.

The authoritative logo file is the version published by the issuer at the
official URL referenced in the project's metadata and documentation.
The copy contained in this directory is provided for completeness,
verification, and archival purposes.

The SHA-256 hash recorded in the Branding Registry of
`docs/TOKEN_IDENTITY.md` constitutes the canonical integrity reference
for the logo.

Branding updates are governed and may introduce new asset versions.
Historical versions should be preserved in this directory in accordance
with the governance rules defined in `docs/TOKEN_IDENTITY.md`.
